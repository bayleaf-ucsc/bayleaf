# Process notes

Working records from building Pouch, kept so the commit history has its reasons
beside it. Not documentation of current behavior (see README.md, JOURNEYS.md,
LANGUAGE.md): these are snapshots, and some describe designs since changed.

- `surveys/`: background research by subagents (sources cited inside):
  steer vs queue in agent UIs, small local models, media and data tools.
- `playtests/round1..3/`: a player agent's observation log (`LOG.md`) and an
  independent critic's evaluation from that evidence only (`CRITIQUE.md`,
  gemini-4-argon). Screenshots and videos are not kept (size).
- `batches/`: one-line progress notes each implementing subagent kept while it
  worked, named by batch or feature.
