# Support

BayLeaf is currently a one-person operation, run by
[Adam Smith](https://campusdirectory.ucsc.edu/cd_detail?uid=amsmith) (Dept. of
Computational Media). With the help of coding agents, we can meaningfully act
on major feature requests on timescales that multi-team platform support
organizations could not. That said, response times depend on teaching schedules
and other duties: your patience is appreciated.

## Public Issues (GitHub)

The best way to request features, report bugs, ask for spend limit increases,
or ask general questions is through a public GitHub issue. Issues are tracked,
searchable, and visible to the whole community, so others can see if their
question has already been answered.

- [API Issue](https://github.com/bayleaf-ucsc/bayleaf/issues/new?template=bayleaf-api.yml)
- [Chat Issue](https://github.com/bayleaf-ucsc/bayleaf/issues/new?template=bayleaf-chat.yml)
- [General Issue](https://github.com/bayleaf-ucsc/bayleaf/issues/new)

Common reasons to file an issue:

- Bug reports (API errors, unexpected behavior in Chat)
- Feature requests and enhancements
- API key requests or daily spend limit increases
- Integration help for coding agents and other API clients
- Questions about privacy, data retention, or available models (see
  [PRIVACY.md](PRIVACY.md))
